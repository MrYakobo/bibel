# bibelord web

Interface för att fetcha och göra slides för bibelord enkelt.

Rewrite pga stabilitetsproblem med Firebase och bibelAPIet.
Nu gör vi allt monolitiskt istället, najs.

## Features

- [x] Välja mellan sfb15 och sfb98
- [x] Ingen komplicerad parsing (?) för att lista ut vilket bibelord man vill ha
- [x] Man ska kunna ändra i texten vid behov
- [x] Displayen ska innehålla minimal logik, och bygga på polling
- [x] Live-display i adminpanelen
